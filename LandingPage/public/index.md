# FlowDown AI

FlowDown AI is a privacy-first native AI workspace for iPhone, iPad, and Mac.

## What it does

- Runs AI conversations in a fast native Apple-platform app.
- Connects to OpenAI-compatible providers through custom model profiles.
- Supports local MLX and Apple Intelligence workflows where available.
- Provides MCP client support for external tools.
- Includes web search, attachments, memory, Calendar tools, location tools, URL metadata, and rich Markdown rendering.
- Supports Apple Shortcuts automation and deep links.
- Stores conversations locally by default, with optional iCloud sync.
